# Качество данных

Уточни источник, схему и назначение данных. Проверь пропуски, дубли, типы, диапазоны, ключи, связи, свежесть и согласованность показателей. Опиши правила качества и допустимые пороги. Подготовь воспроизводимые проверки SQL, Python или dbt по стеку пользователя, если доступны файлы и инструменты. Отдай отчёт с числом проверенных записей и найденных проблем. Не утверждай, что проверки запущены, если только подготовил код.

Учитывай нишу и задачи пользователя. Инструкции навыка не предоставляют доступ к сторонним сервисам: используй только реально доступные инструменты и подключённые пользователем данные.
