# Debugging and Error Recovery

## Обзор
Систематический дебаг со структурным триажем. Когда что-то сломалось — стоп фичам, сохрани улики, найди и почини корневую причину. Гадание тратит время.

## Когда использовать
- Тесты падают после изменений
- Сборка сломалась
- Рантайм не соответствует ожиданиям
- Пришёл багрепорт
- Ошибка в логах/консоли
- Вчера работало — сегодня нет

## Stop-the-Line Rule
При любом неожиданном сбое:
```
1. STOP — не добавляй фичи и не меняй код
2. PRESERVE — сохрани улики (вывод ошибки, логи, шаги воспроизведения)
3. DIAGNOSE — пройди чек-лист триажа
4. FIX — починить корневую причину
5. GUARD — защита от повтора (тест-регрессия)
6. RESUME — только после зелёной проверки
```
Не иди мимо падающего теста к следующей фиче — ошибки накапливаются.

## Чек-лист триажа (по порядку, не пропуская)

### Step 1: Reproduce
Сделай сбой стабильным. Не воспроизводится — не починишь уверенно.
- Воспроизводится → шаг 2
- Нет → собери контекст (логи, окружение), попробуй минимальную среду; если правда случайный — задокументируй условия и мониторь
- Timing-зависимый → таймстампы в логах, искусственные задержки, нагрузка/конкурентность
- Environment-зависимый → версии Node/браузера, ОС, переменные окружения, данные, чистый CI
- State-зависимый → утечки состояния между тестами/запросами, глобалы, синглтоны, кэши; изоляция сценария

### Step 2: Localize
Найди минимальную точку сбоя — бисекция по коммитам, отключение частей, добавление логов вокруг подозреваемого места.

### Step 3: Fix the root cause
Чини причину, а не симптом. Не глотай исключения, не маскируй.

### Step 4: Guard
Добавь тест-регрессию (см. test-driven-development, Prove-It Pattern) или алерт.

## Команды (подставь команды своего репо)
```bash
# один упавший тест
npm test -- --grep "test name"
# подробный вывод
npm test -- --verbose
# только упавшие
npm test -- --bail
```

## Ошибки, которых избегать
- Гадание вместо воспроизведения
- Правка симптома без понимания причины
- Работа поверх падающего теста/сборки
- Удаление непонятного кода "на всякий случай"
