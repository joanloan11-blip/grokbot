# Spreadsheets (XLSX)

## Обзор
Анализ и создание Excel-файлов: чтение, формулы, стили, проверка расчётов, сводные.

## Чтение
- openpyxl — структура, формулы, стили, листы; pandas — табличный анализ
- Формулы: openpyxl возвращает строку формулы по умолчанию; для значений нужен data_only=True (берёт кэш, важен после открытия в Excel) 
- Крупные файлы: read_only=True, иначе память съедается

## Создание
- openpyxl для форматирования (ширины, стили, форматы чисел), pandas для массивов
- Формула пишется как `=SUM(A1:A10)`; при изменении пересчёт будет при открытии в Excel
- Не теряй важные листы при перезаписи — открывай существующий workbook, а не создавай новый

## Проверка расчётов
- Сверяй итоги и краевые (пустые, отрицательные, даты в текстовом формате)
- Проверяй, что нет #REF/#DIV0/#N/A
- Для больших таблиц — суммы по столбцам и контрольная сверка с исходником

## Правила
- Не перезаписывай исходный файл без бэкапа
- Сохраняй как .xlsx (не теряй форматирование)
- Не ставь формулы там, где нужно статичное значение (и наоборот) без запроса

## Ошибки-паттерны
- Чтение формул без data_only и интерпретация строки как числа
- Дата в виде числа (Excel serial)
- Смещение строк из-за заголовков

## Требования
```bash
pip install openpyxl pandas
```
