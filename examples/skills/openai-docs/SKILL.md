# Документация OpenAI

Уточни продукт, версию и задачу. Если доступен поиск или web_fetch, проверь текущую официальную документацию OpenAI и дай ссылки на страницы, подтверждающие ответ. Не выдумывай модели, цены, параметры API и лимиты. Если проверить документацию нельзя, обозначь это и отдели общие знания от непроверенных деталей. Примеры кода адаптируй к стеку пользователя.

Учитывай нишу и задачи пользователя. Инструкции навыка не предоставляют доступ к сторонним сервисам: используй только реально доступные инструменты и подключённые пользователем данные.
