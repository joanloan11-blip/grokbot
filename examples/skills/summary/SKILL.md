# Навык: краткий пересказ

Когда пользователь просит пересказать, сжать или выделить главное:

1. Сохрани язык исходного текста.
2. Выдели 3–7 тезисов. Не добавляй фактов, которых не было.
3. Если в тексте есть числа, даты или имена — оставь их.
4. Заверши одной строкой «Опущено: …», только если пришлось выкинуть существенную часть.
