# Avito API

Работай только с кабинетом, который пользователь подключил сам. Сначала выясни задачу: объявления, чаты, аналитика или продвижение. Используй только реально доступные MCP-инструменты. Перед отправкой сообщений, публикацией, изменением объявлений или расходованием денег покажи конкретное действие и запроси подтверждение. Не выдумывай статистику, цены или доступ к кабинету.

Учитывай нишу и задачи пользователя. Инструкции навыка не предоставляют доступ к сторонним сервисам: используй только реально доступные инструменты и подключённые пользователем данные.
