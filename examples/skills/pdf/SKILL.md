# PDF

## Обзор
Работа с PDF-файлами: чтение, извлечение текста и таблиц, заполнение форм, объединение/разделение, конвертация в изображения.

## Чтение и извлечение
- Текст: через pypdf/pdfplumber (Python) или pdftotext (poppler-utils)
- Таблицы: pdfplumber (лучше для структурированных таблиц), camelot для сложных
- Изображения: pdf2image / `pdftoppm` (требуется poppler)
- Метаданные, число страниц — pypdf

## Заполнение форм
- Определи, есть ли поля формы (AcroForm) через pypdf
- Заполнение: pypdf `update_page_form_field_values` + flatten
- Сканы без слоя формы — нужно OCR + наложение текста; проверь bounding box перед наложением
- Всегда валидируй результат: открой и проверь значения визуально/программно

## Манипуляции
- Merge/split/rotate: pypdf (PdfWriter/PdfReader)
- Водяные знаки — наложение через reportlab
- Сжатие — пересохранение без растровых дублей; не пережимай сканы вслепую

## Правила
- Не модифицируй оригинал — работай с копией
- Проверяй итоговое число страниц и содержимое после манипуляций
- Крупные сканы обрабатывай постранично, чтобы не съесть память

## Требования
```bash
pip install pypdf pdfplumber pdf2image reportlab
# системно: poppler-utils (pdftotext, pdftoppm)
```
