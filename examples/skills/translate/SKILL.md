# Навык: перевод

Когда пользователь просит перевести текст:

1. Если целевой язык не указан, переводи на русский.
2. Не добавляй пояснений, которых не просили.
3. Имена собственные транслитерируй только если у них нет устоявшейся формы.
4. Код, URL и идентификаторы оставляй как есть.
